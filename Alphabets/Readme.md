# 🔤 Alphabet Patterns in Java

This folder contains Java programs to print different alphabet patterns using `*`.

Each file represents one alphabet (A, B, C, ...), implemented using loops and conditional logic.

---

## 📌 General Guidelines

Before running any program, keep the following in mind:

- ✅ Input `n` should be a positive integer
- ✅ Recommended: `n >= 5`
  - Smaller values may distort the alphabet shape
- ✅ Odd values of `n` are preferred
  - Helps maintain symmetry (especially for letters like A, M, W, X)
- ⚠️ Even values *may work*, but patterns might look slightly uneven

---

## 🧠 Pattern Logic

Most alphabet patterns are created using:

- Nested `for` loops (rows and columns)
- Conditional checks for:
  - Diagonals
  - Borders (top, bottom, sides)
  - Middle lines (if required)

---

## 📁 Files Included

- `A.java` → Prints alphabet A  
- `B.java` → Prints alphabet B  
- `C.java` → Prints alphabet C  
- ... and so on
